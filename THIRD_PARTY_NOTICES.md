Aster's own source is MIT licensed. Dependencies and model assets retain their own licenses. The source repository does not contain downloaded model weights.

- Electron / Chromium — MIT and Chromium component licenses, included by Electron in packaged distributions. https://www.electronjs.org/
- React — MIT. https://github.com/facebook/react
- Vite — MIT. https://github.com/vitejs/vite
- Lucide icons — ISC. https://lucide.dev/license
- MediaPipe and Hand Landmarker — Google / Apache-2.0; model source: https://storage.googleapis.com/mediapipe-models/hand_landmarker/hand_landmarker/float16/1/hand_landmarker.task
- Kokoro JS and Kokoro-82M — Apache-2.0; the model LICENSE is packaged beside the model. https://github.com/hexgrad/kokoro and https://huggingface.co/onnx-community/Kokoro-82M-v1.0-ONNX
- ONNX Runtime — MIT. https://github.com/microsoft/onnxruntime
- Ollama — MIT; downloaded separately. https://github.com/ollama/ollama
- Qwen 3.5 model — its upstream model license applies; downloaded separately via Ollama. https://ollama.com/library/qwen3.5

Consult each installed package's license for full notices, including transitive dependencies. The downloadable app retains node_modules license files and Electron's bundled notices. No Iron Man/JARVIS artwork, logo or audio is included; Aster's dashboard uses original CSS/SVG visuals.
