# Security reports

Do not post credentials, private messages, screen recordings or personal workspace files in issues. Use GitHub's private vulnerability reporting if enabled on the repository; otherwise contact the maintainer before sharing sensitive details.

Aster is an experimental desktop controller. Permissions authorize substantial access. The model has a constrained action grammar, not a general shell tool. Explicit voice clicks and Enter can still submit actions in the focused app. Review the visible target before sending, purchasing or making other consequential changes.

Security-sensitive macOS permission dialogs remain user-controlled. Community builds are not notarized, independently audited or guaranteed safe for high-stakes use. Supported version: current 0.4 preview only.
